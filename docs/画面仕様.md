# 画面仕様

> **対象**: v0.1.0（コミット `cb328d4` 時点）
> **正はコード**: 寸法は `src/style.css` の `:root`、描画は `src/game.js`、ウィンドウは `electron/main.js`。

---

## 1. 全体構成

画面右下に**透過ウィンドウ**を1枚置き、その中に「カード」と「パネル」を描く。ウィンドウの余白部分はクリックが下のアプリに抜ける。

```
                       画面の右下（タスクバーを除いた作業領域）
┌──────────────── ウィンドウ 508 × 546px（透明）────────────────┐
│                                                              │
│  ┌──────────────── パネル 480 × 320px ──────────────────┐   │  ← 強化／図鑑を開いたときだけ
│  │  🔧 強化                                        [×]  │   │     下から伸びる（0.18秒）
│  │  ...                                                 │   │
│  └──────────────────────────────────────────────────────┘   │
│                         ↕ 8px                                │
│  ┌──────────────── カード 480 × 190px ──────────────────┐   │  ← 常に表示
│  │                  （地中の断面・Canvas）                │   │
│  │                        ▓▓                             │   │
│  │                       [ドリル]                         │   │
│  │                                                       │   │
│  ├───────────────────────────────────────────────────────┤   │
│  │ 2,633m [化石層] 次の鉱脈まで130m   💰6,305G 🔧📖⏸× │   │  ← HUD 34px
│  └──────────────────────────────────────────────────────┘   │
│                                                    14px →  │
└──────────────────────────────────────────────────────────────┘
                                                       ↑ 14px
```

### 寸法

| 項目 | 値 | 定義場所 |
|---|---:|---|
| カード幅 | 480px | `--card-w` |
| カード高さ | 190px | `--strip-h` |
| パネル高さ | 320px | `--panel-h` |
| 外側の余白 | 14px | `--margin` |
| カードとパネルの間 | 8px | `style.css` に直書き |
| 角丸 | 14px | `--radius` |
| 影 | `0 8px 28px rgba(0,0,0,0.45)` | カードとパネル |
| ウィンドウ | 508 × 546px | `electron/main.js` で計算 |

> **寸法は3箇所で揃える必要がある**: `style.css` の `:root`、`game.js` の `STRIP_H` と `DRILL_Y`、`electron/main.js` の `CARD_W` `STRIP_H` `PANEL_H` `MARGIN`。1箇所だけ変えるとずれる。

## 2. カード（地中の断面）

### 2.1 縦方向のレイアウト

カードの高さ190pxのうち、下34pxはHUDに覆われる。

| y座標 | 内容 |
|---:|---|
| 0〜12 | 上端の陰（断面の縁に見せるためのグラデーション）と、1pxのハイライト |
| 0〜66 | 掘ってきた坑道（ドリルの上に黒い縦帯） |
| 24〜58 | ドリル本体（34 × 34px） |
| 58〜80 | 回転するビット |
| **66** | **ドリル先端 = 現在の深度**（`DRILL_Y`） |
| 88〜146 | 鉱脈UI／結果表示の領域 |
| 156〜190 | HUD（DOM要素） |

**縮尺**: 1m = 3px（`PPM`）。カードには現在の深度の約22m上から41m下までが映る。

### 2.2 描画の重なり順

奥から順に描く。

1. 地層の色（1pxずつ横線で塗る）
2. 小石のまだら模様
3. 地表の草（深度が浅いときだけ見える）
4. 地層の境界線とラベル
5. 鉱脈（近づいてきたときだけ）
6. 坑道
7. ドリル
8. パーティクル
9. 上端の陰
10. フラッシュ（画面全体）
11. 鉱脈UI または 結果表示

### 2.3 地層の見た目

| 要素 | 仕様 |
|---|---|
| 地色 | 地層ごとに上端色→下端色へ、地層内の進み具合に応じて補間 |
| 縞模様 | 8mごとに6%暗くする。**下に掘り進んでいる感覚**を出すため |
| 小石 | 22pxのマス目ごとに、ハッシュ関数で32%の確率で楕円を置く。位置は深度から決まるので、スクロールしても同じ場所に同じ石がある |
| 境界線 | 地層の切り替わりに黒い線と「▼ 化石層 2,000m」のラベル |
| 地表 | 深度0mに緑の草（`#5a8f3c`）。それより上は薄い水色 |

### 2.4 ドリル

| 要素 | 仕様 |
|---|---|
| 本体 | 濃紺の四角（`#2f3542`）、上部にオレンジの帯（`#ff7a45`）、水色の窓（`#8ad4ff`） |
| ビット | 銀色の逆三角形。斜線が流れて回転して見える。掘削中は速度6、鉱脈中は14 |
| 揺れ | 掘削中だけ上下に±1.2px振動 |

## 3. 状態ごとの表示

### 3.1 掘削中（`dig`）

- ドリルが振動し、白い粉塵が毎秒約12個舞う
- 鉱脈が近づくと、ドリルの下に金色の鉱石の塊がせり上がってくる（光が約1.1秒周期で脈打つ）
- HUD に「次の鉱脈まで ○○m」

### 3.2 鉱脈（`hit`）

開始の瞬間に画面全体が金色にフラッシュする。

```
┌─────────────────────────────────────┐  y=90
│      鉱脈発見！ クリックで掘り出せ      │  y=104（金色の文字）
│ ┌──┬───────────────┬─────────────┐  │  y=114〜130
│ │▓▓│▓▓▓▓            │             │  │  ゲージ（青→緑のグラデーション）
│ └──┴───────────────┴─────────────┘  │
│ ━━━━━━━━━━━━━━━━━━━━━              │  y=134〜138（残り時間。30%を切ると赤）
└─────────────────────────────────────┘  y=146
   ↑15%               ↑70%
  失敗ライン          自動で溜まる上限
```

| 要素 | 仕様 |
|---|---|
| ゲージ | 幅280px × 高さ16px。カード中央 |
| 目盛り | 15%（失敗ライン）と70%（自動ゲージの上限）に白い縦線 |
| 残り時間バー | 幅が残り時間に比例して縮む。残り30%を切ると赤（`#ff6b6b`） |
| クリック時 | 金色の火花が8個飛び散り、カードが横に±1.5px揺れる |
| HUD | 「採掘中！」 |

### 3.3 結果（`result`）

2秒間表示し、最後の0.5秒でフェードアウトする。

```
┌────────────────────────────────────────┐  y=88
│  🦴          恐竜の骨  NEW!             │  ← 名前はレア度の色
│              +1,680 G                   │  ← 金色
└────────────────────────────────────────┘  y=140
          ↑ 枠線もレア度の色
```

| 要素 | 仕様 |
|---|---|
| 枠 | 300 × 52px。枠線の色はレア度の色（`ゲーム仕様.md` §7） |
| NEW! | 図鑑に初めて登録されたとき |
| フラッシュ | 希少・伝説のときだけ、もう一度画面全体がフラッシュする |
| 失敗時 | 「逃してしまった…」（赤）。ただし現状は到達不能（`ゲーム仕様.md` §6） |
| HUD | 「回収中…」 |

### 3.4 一時停止中

- 掘削・鉱脈のタイマー・ゲージがすべて止まる
- ドリルの振動とビットの回転も止まる
- HUD の⏸ボタンが▶に変わる

## 4. HUD

カード下部の34px。半透明の黒（`rgba(10,12,16,0.78)`）にぼかし。

```
2,633m [化石層] 次の鉱脈まで130m            💰 6,305 G  [🔧][📖][⏸][×]
└深度  └地層    └状態                       └所持金     └強化 図鑑 停止 終了
```

| 要素 | 内容 |
|---|---|
| 深度 | 小数点以下切り捨て、3桁区切り。16px太字 |
| 地層 | 角丸のバッジ |
| 状態 | 掘削中「次の鉱脈まで ○○m」／鉱脈中「採掘中！」／結果中「回収中…」。幅が足りなければ「…」で省略 |
| 所持金 | 1万以上は「6.3万」、1億以上は「1.23億」 |
| 🔧 | 強化パネルを開閉 |
| 📖 | 図鑑パネルを開閉 |
| ⏸ / ▶ | 一時停止／再開 |
| × | 保存して終了。ホバーで赤くなる |

- 表示の更新は0.1秒ごと（描画は毎フレーム）
- **HUDの何もないところを掴むとウィンドウを移動できる**（ボタンの上は不可）

## 6. おかえりトースト

起動時に放置精算が発生したときだけ、パネルと同じ位置に9秒間表示する。

> おかえりなさい。**45**分の放置で **2,700m** 掘り進み、鉱脈 **18** 件から **1.2万 G** を回収しました。

数値部分は金色。表示中もクリックは下に抜ける（`pointer-events: none`）。

## 8. クリック透過

**ウィンドウ全体は普段「クリック透過」になっていて、カーソルがカードかパネルの上に来たときだけ透過を解除する。**

| 仕様 | |
|---|---|
| 初期状態 | 透過（下のアプリにクリックが届く） |
| 判定 | マウスが動くたびに、カーソル位置の要素がカード（`#app`）かパネル（`#panel`）の中かを調べる |
| 判定方法 | 座標計算ではなく実際の要素に当てる（`elementFromPoint`）。CSSでレイアウトを変えても自動で追従する |
| 実装 | `src/desktop.js`（Electron のときだけ動く） |

| 項目 | 仕様 |
|---|---|
| 枠 | なし（タイトルバーなし） |
| 背景 | 完全に透明 |
| 最前面 | 常に最前面（レベル `normal`） |
| サイズ変更 | 不可 |
| タスクバー | 表示する |

## 11. 判明している画面上の課題

| # | 課題 | 原因 |
|---|---|---|
| 1 | 図鑑を開いたまま鉱脈が終わると、スクロール位置が先頭に戻る | 結果が出るたびにパネルのHTMLを丸ごと作り直している |
| 2 | おかえりトーストとパネルが同じ位置に重なる | 起動直後の9秒間にパネルを開くとトーストが隠れる |
| 3 | アイコンの見た目がOSで違う | 絵文字フォントで描いている。Windows用の `Segoe UI Emoji` を指定しているので Mac では別のフォントになる |
| 4 | 文言がコードに直書きされている | 多言語化（Steamでの英語対応）の前に外に出す必要がある |
| 5 | 希少以上のフラッシュ判定が数値 `260` の直書き | 旧バランス（希少の価値が260だった頃）の名残り。今の値でも結果は正しいが、レア度名で判定すべき |
| 6 | ドラッグした位置が記憶されない | 再起動すると右下に戻る |
| 7 | プライマリディスプレイ以外に置けない | 初期位置の計算がプライマリ固定 |
| 8 | 別の解像度のモニタへ移すと、Canvas がぼやける可能性 | 解像度倍率（devicePixelRatio）の変化を監視していない |
