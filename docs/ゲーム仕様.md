# ゲーム仕様

> **対象**: v0.1.0（コミット `cb328d4` 時点）
> **正はコード**: 数値は `src/data.js`、ルールは `src/game.js` が正しい。この文書と食い違ったらコードに合わせてこの文書を直す。
> **表の出どころ**: 地層・収集物・強化の表は `src/data.js` から、推移の表は `tools/balance-sim.js` から生成したもの。手で書き換えないこと。

## 1. コンセプト

**画面の右下で勝手に地面を掘り進み、ときどき来る鉱脈の数秒だけ手を出す、放置型の採掘コレクションゲーム。**

| | |
|---|---|
| ジャンル | デスクトップ常駐型 × 放置（Idle） × 収集 |
| 同系統 | Cornerpond（釣り）、Idle Waters（釣り）、ねこねこ釣り日記（釣り）、デスクトップ小動物牧場 |
| 差別化 | 題材が「採掘」。深く潜るほど地層が変わり、出てくるものが変わる |
| 最終目標 | Steam で有料販売 |

### 体験の柱

1. **作業の邪魔をしない** — カードの外はクリックが下のアプリに抜ける。音は出さない。中断は150秒に1回
2. **見ていれば得をする** — 鉱脈で手動でゲージを満たすと、放置の約3倍の報酬（§8）
3. **潜るほど未知に出会う** — 地層ごとに見た目と収集物が変わる

---

## 2. コアループ

```
[放置] ドリルが自動で掘り進む（深度が増える）
   │  平均150秒ごと
   ▼
[鉱脈] 4.5秒の連打チャンス。ゲージは自動でも溜まるが、満タンはクリックでしか届かない
   │
   ▼
[回収] ゲージの到達率で、収集物のレア度と報酬（G）が決まる → 図鑑に登録
   │
   ▼
[強化] Gで5種類の強化を買う → 速く深く掘れる／レアが出やすくなる／放置が強くなる
   │
   └──→ [放置] に戻る
```

## 3. 状態遷移

ゲームは常に次の3状態のどれかにある。これとは別に「一時停止」フラグがある。

```
        veinTimer が 0 になる          4.5秒経過
  dig ─────────────────────→ hit ─────────────→ result
   ▲                                                 │
   └───────────────────── 2.0秒経過 ─────────────────┘
                     （次の veinTimer をセット）
```

| 状態 | 何が起きるか | 掘削 | 終了条件 |
|---|---|:-:|---|
| `dig` | 深度が増え、`veinTimer` が減る | 進む | `veinTimer ≤ 0` |
| `hit` | ゲージが自動で溜まる。クリック／Space で加算 | **止まる** | 4.5秒経過 |
| `result` | 獲得物を表示 | **止まる** | 2.0秒経過 |
| 一時停止中 | すべての進行が止まる（演出のパーティクルだけ動く） | 止まる | ⏸ボタンで解除 |

- 鉱脈1回につき **6.5秒** 掘削が止まる（4.5 + 2.0）
- 一時停止は保存されない。次回起動時は必ず解除された状態で始まる

---

## 4. 掘削

| 項目 | 仕様 |
|---|---|
| 速度 | `1 + ドリル出力Lv × 0.6` m/秒 |
| 方向 | **下にしか進まない。浅い地層には戻れない** |
| 止まる条件 | `hit` / `result` 中、一時停止中 |

> 「戻れない」ことが、§15-1 の図鑑問題の直接の原因になっている。

---

## 5. 鉱脈

| 項目 | 仕様 |
|---|---|
| 初回 | ゲーム開始から **20秒** |
| 2回目以降の間隔 | `max(45, 150 - ソナーLv × 5)` 秒 × **0.75〜1.25 の乱数** |
| 接近の演出 | 残り時間 × 掘削速度 を距離に換算し、金色の鉱石が下からせり上がってくる |

### 設計判断：間隔は「距離」ではなく「時間」で決める

当初は180mごとだったが、これだと**掘削速度を強化するほど中断が増える**（ドリルLv6で39秒に1回）。常駐ツールとして邪魔になるため、時間で固定した。画面上は残り時間を距離に読み替えているので、見え方は変わらない。

### 既知の挙動

- 鉱脈の最中（`hit` / `result`）にアプリを終了すると、その鉱脈は消える。再起動後は新しい間隔から始まる

## 6. 連打ゲージ

| 項目 | 仕様 |
|---|---|
| 制限時間 | 4.5秒 |
| 自動で溜まる量 | `0.045 + バッテリーLv × 0.015` /秒。**0.7で頭打ち**。減衰はしない |
| クリック1回 | `+(0.11 + ハンマーLv × 0.025)`。上限1.0 |
| 入力 | カード上のマウスクリック、または Space キー |
| 品質 | 4.5秒経過時点のゲージ値（0〜1）がそのまま「品質」になる |
| 失敗ライン | 品質 0.15 未満なら失敗（何も得られない） |

### 設計判断：自動ゲージの上限を0.7にする

- **放置でも最低限は回収できる**：初期状態でも4.5秒で0.2025まで溜まる
- **満タンは必ず手動**：0.7から先はクリックでしか届かない。「見ていれば得をする」を保証する

### 既知の挙動：失敗は現状発生しない

自動ゲージだけで4.5秒後に **0.2025** に達し、失敗ライン **0.15** を必ず超える。一時停止中は時間も止まるので、そこでも失敗しない。つまり**「逃してしまった…」の表示は現状の数値では到達不能**。残すかどうかは未決（`未決事項.md`）。

### 満タンに必要なクリック数（目安）

自動ゲージの寄与があるので、連打のタイミングで多少変わる。

| ハンマーLv | クリック1回 | 必要回数の目安 |
|---:|---:|---:|
| 0 | +11% | 8〜10回 |
| 5 | +24% | 4〜5回 |
| 10 | +36% | 3回 |
| 20 | +61% | 2回 |
| 30（MAX） | +86% | 1〜2回 |

## 7. 収集物の抽選

鉱脈を掘り出したとき、**今いる地層の収集物の中から**重み付きで1つ選ぶ。

```
重み = レア度の基本重み × レア度ボーナス
ボーナス値 b = 品質 × 0.35 + 特殊ビットLv × 0.06
```

| レア度 | 基本重み | ボーナス倍率 | 基本価値 | 表示色 |
|---|---:|---|---:|---|
| 並 | 100 | ×1（変わらない） | 25 | `#b9c2cc` |
| レア | 30 | ×(1 + 2b) | 120 | `#4fc3f7` |
| 希少 | 6 | ×(1 + 3.5b) | 700 | `#ba68c8` |
| 伝説 | 1 | ×(1 + 5b) | 5,000 | `#ffb300` |

## 8. 報酬（G）

```
獲得G = レア度の基本価値 × 深度倍率 × 品質係数

深度倍率 = 2 ^ (地層番号 + 地層内の進み具合)
品質係数 = 0.25 + 品質 × 1.5        （0.25〜1.75）
```

- **深度倍率**は地層を1つ下るごとに2倍。地層の中でもなめらかに増える（入口×1 → 出口×2）
- 最後の「未知領域」より先は、8,000mごとに2倍で**際限なく伸びる**

### 計算例：化石層の入口（2,000m）で「恐竜の骨」（レア）

| | 品質 | 品質係数 | 獲得G |
|---|---:|---:|---:|
| 手動で満タン | 1.00 | 1.75 | 120 × 8 × 1.75 = **1,680** |
| 完全放置 | 0.2025 | 0.554 | 120 × 8 × 0.554 = **531** |

価値だけで約3.2倍。加えて満タン時はレアが出やすくなるので、実際の差はさらに開く（§14.2 で約4倍）。

## 12. 放置精算（アプリを閉じていた間）

起動時に、前回の保存時刻からの経過時間をまとめて精算する。

| 項目 | 仕様 |
|---|---|
| 発動条件 | 前回保存から **60秒以上** 経過 |
| 精算する時間 | 経過時間。ただし上限は `2 + バッテリーLv` 時間 |
| 掘削 | `掘削速度 × 精算時間`（鉱脈中の停止6.5秒は考慮しない） |
| 鉱脈の数 | `精算時間 ÷ 鉱脈の間隔` の切り捨て（乱数のばらつきなし） |
| 品質 | 自動ゲージのぶんだけ：`min(0.7, 自動ゲージ/秒 × 4.5)` |
| 収集物 | 1件ずつ通常どおり抽選し、図鑑にも記録する |
| 精算後 | 次の鉱脈までの時間を通常の間隔にリセット |
| 通知 | 「おかえりなさい」トーストを9秒表示（`画面仕様.md`） |

### 既知の挙動：起動したままのスリープは精算されない

精算は**起動時にしか行わない**。アプリを起動したままPCがスリープすると、復帰後の最初のフレームで経過時間が0.1秒に切り捨てられ、その間の進行は失われる。常駐ツールでは「起動したまま閉じる」が普通の使い方なので影響が大きい（`未決事項.md`）。

## 14. バランス設計

### 14.1 方針

**収集物の価値も、強化の価格も、どちらも指数で伸ばす。** 片方だけ指数だと、もう片方が必ず追いつけなくなる。

価値の伸び（深度倍率の底）は4つの候補をシミュレータで比較し、**2.0** を採用した。

| 底 | 結果（アクティブプレイ） |
|---:|---|
| **2.0（採用）** | 120分で Lv 23/23/19/19/19。**どの強化もMAXにならない** |
| 2.5 | 90分でソナー・バッテリーがMAX。120分で5種中4種がMAX |
| 3.0 | 90分でドリル以外の4種がMAX。120分で全種MAX |
| 4.0 | 60分でドリル以外の4種がMAX。90分で全種MAX。所持Gが「394万億」に達する |

Lv の並びは「ドリル出力／ハンマー／特殊ビット／ソナー／バッテリー」。

### 14.4 シミュレータの前提

`tools/balance-sim.js` は `src/data.js` を直接読み込むので、テーブルを変えれば結果も変わる。ただし次の点は単純化している。

- 0.5秒刻みで進める
- 鉱脈の間隔の乱数（±25%）は平均値で代用
- 収集物は抽選せず期待値で加算
- 強化は「買える中で一番安いもの」から即購入
- ゲーム側の定数（4.5秒・2.0秒・0.7・初回20秒）はシミュレータ内に複製している。**`game.js` を変えたらシミュレータも直す**

## 15. 判明している設計上の課題

仕様書を作る過程で見つかったもの。対応方針は `未決事項.md` で決める。

### 15-1. 図鑑が構造的に埋まらない【最重要】

§14.3 の通り、表土は**6種あるのに鉱脈が1〜2回**しか来ない。粘土層・石灰岩も2回ずつ。しかも深度は下にしか進まず（§4）、通過した地層には二度と戻れない。

最初の3地層（16種）を、合計5〜6回の抽選で通過することになる。粘土層の伝説「封印された壺」は満タンでも約97回に1回なので、**事実上一生出ない**。図鑑のコンプリートがこのゲームのエンドコンテンツのはずなのに、それが原理的に不可能になっている。

### 15-2. 1時間で全地層を通過し、以降は景色が変わらない

アクティブなら46分、放置でも57分で最終地層の未知領域に着く。以降は数値が増えるだけで、見た目も収集物も変わらない。Steam で販売するには遊びの寿命が短い。

### 15-3. 失敗が発生しない

§6 の通り、自動ゲージだけで失敗ラインを超える。失敗の分岐と表示は到達不能なコードになっている。

### 15-4. バッテリーの説明文が実態と合わない

§11 の通り、自動ゲージの効果はLv8で頭打ちになるが、説明文は増え続ける。

### 15-5. 伝説が7地層中4地層にしかない

表土・石灰岩・玄武岩には伝説がない。地層ごとの「目玉」の有無にばらつきがある。

### 15-6. 「兆」の単位がない

金額の表示は「億」が最大。1兆を超えると「10000.00億」のようになる。現行の底2.0なら2時間では届かないが、長時間遊べば到達する。
