# 仕様書

Deskavation（画面右下に常駐する放置採掘ゲーム）の仕様書群。

## 文書

| 文書 | 内容 | こんなときに読む |
|---|---|---|
| [未決事項.md](未決事項.md) | 決まっていない企画判断と、仕様書づくりで見つかった課題。推奨案つき | **最初に読む**。次に何を決めるか |
| [ゲーム仕様.md](ゲーム仕様.md) | ルール・数値・地層・収集物・強化・バランスの根拠 | 遊びの中身を変えるとき |
| [画面仕様.md](画面仕様.md) | カード・HUD・パネルのレイアウト、演出、操作、ウィンドウの振る舞い | 見た目や操作を変えるとき |
| [技術仕様.md](技術仕様.md) | 構成・ゲームエンジンを使わない理由・保存形式・技術的負債・Steam 向けの課題 | 実装の前に |

## 更新のルール

1. **正はコード。** 文書とコードが食い違ったら、コードに合わせて文書を直す
2. **数値を変えたら文書も直す。** 特に `src/data.js` を変えたら、`ゲーム仕様.md` の表を作り直す
3. **表は手で書かない。** 地層・収集物・強化の表は `src/data.js` から、推移の表は `tools/balance-sim.js` から出力したものを貼る
4. **未決事項が決まったら**、`未決事項.md` の状態を「決定」にして内容を書き、関係する仕様書に反映する

## ツール

```bash
node tools/balance-sim.js              # バランスの推移（アクティブ／放置、各120分）
node tools/balance-sim.js --base 2.5   # 価値の伸びを変えて比較
node tools/balance-sim.js --minutes 60 # 時間を変える
node tools/drop-rates.js               # 地層ごとの出現確率（代表3パターン）
node tools/drop-rates.js --quality 1 --bit 5
```

どちらも `src/data.js` を直接読むので、テーブルを変えれば結果も変わる。
