# Deskavation（ほりさげデスク）

画面の**右下**に常駐して、勝手に地面を掘り進む放置ゲーム。
ふだんは眺めているだけで、**鉱脈に当たった数秒だけ**クリックで関与する。
掘り出した鉱物・化石・遺物は図鑑に溜まっていく。Steam での販売を目指している。

## 遊び方

| | |
|---|---|
| 放置 | ドリルが自動で深度を稼ぐ。地層が変わると出てくるものが変わる |
| 鉱脈 | 約2.5分に1回（初回は20秒後）「鉱脈発見！」。4.5秒の連打チャンス |
| ゲージ | 自動でも70%まで溜まる。そこから先はクリック（または Space）でしか届かない。満たすほど高レア・高報酬 |
| 強化 | 稼いだGで ドリル出力 / ハンマー / 特殊ビット / ソナー / バッテリー を強化 |
| 放置報酬 | 終了中の経過時間も起動時に精算される（上限はバッテリーのLvで伸びる） |

詳しいルールと数値は [docs/ゲーム仕様.md](docs/ゲーム仕様.md)。

## 動かす

### ブラウザで試す（インストール不要）

`index.html` をブラウザで開くだけ。ゲームロジックの確認用。

### デスクトップ常駐（Electron）

```bash
npm install
npm start
```

画面右下に 480×190px のカードが出る（強化・図鑑を開くとその上に伸びる）。
カードの外はクリックが下のアプリに抜けるので、作業の邪魔にならない。
下部の黒いバーを掴めば移動でき、終了はその右端の `×`。

### セーブを消す

- Electron：`%APPDATA%\deskavation\` を削除
- ブラウザ：開発者ツールで `localStorage` のキー `deskavation.save.v1` を削除

## 構成

| パス | 役割 |
|---|---|
| `src/data.js` | 地層・収集物・強化のテーブル。**バランス調整はここ** |
| `src/game.js` | 状態・ゲームループ・Canvas 描画・パネル・保存 |
| `src/desktop.js` | クリック透過の判定（Electron のときだけ動く） |
| `src/style.css` | カード・HUD・パネルの見た目。寸法は `:root` |
| `electron/` | ウィンドウ生成・配置・IPC |
| `tools/` | バランス検証シミュレータと出現確率の計算 |
| `docs/` | 仕様書 |
