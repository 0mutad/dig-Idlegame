# Deskavation（ほりさげデスク）

画面の**右下**に常駐して、勝手に地面を掘り進む放置ゲーム。
ふだんは眺めているだけで、**鉱脈に当たった数秒だけ**クリックで関与する。
掘り出した鉱物・化石・遺物は図鑑に溜まっていく。

## 遊び方

| | |
|---|---|
| 放置 | ドリルが自動で深度を稼ぐ。地層が変わると出てくるものが変わる |
| 鉱脈 | 平均2〜4分に1回「鉱脈発見！」。4.5秒以内にクリックでゲージを満たす |
| 結果 | ゲージ20%未満は失敗。満たすほど高レア・高報酬 |
| 強化 | 稼いだGで ドリル出力 / ハンマー / 特殊ビット / ソナー / バッテリー を強化 |
| 放置報酬 | 終了中の経過時間も精算される（上限はバッテリーのLvで伸びる） |

キーボードの **Space** でもゲージを叩ける。

## 動かす

### 1. ブラウザで試す（インストール不要）

`index.html` をブラウザで開くだけ。ゲームロジックの確認用。

### 2. デスクトップ常駐（Electron）

```bash
npm install
npm start
```

画面右下に 480×190px のカードが出る（強化・図鑑を開くとその上に伸びる）。
カードの外はクリックが下のアプリに抜けるので、作業の邪魔にならない。
下部の黒いバーを掴めば移動でき、終了はその右端の `×`。

カードの寸法は `src/style.css` の `:root` 変数、`src/game.js` の定数、
`electron/main.js` の定数の3箇所で揃える必要がある。

## 構成

| ファイル | 役割 |
|---|---|
| `src/data.js` | 地層・収集物・強化のテーブル。**バランス調整はここだけ** |
| `src/game.js` | コアループと Canvas 描画 |
| `src/desktop.js` | クリック透過の領域判定（Electron時のみ） |
| `src/style.css` | HUD とパネルの見た目 |
| `electron/main.js` | ウィンドウ生成・配置・最前面・クリック透過 |

セーブは `localStorage`（キー: `deskavation.save.v1`）。
リセットしたいときはブラウザの DevTools から該当キーを削除する。
